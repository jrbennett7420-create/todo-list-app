# To-Do List App

A simple to-do application built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as complete
- Delete tasks
- Save tasks in browser localStorage so they persist after refresh

## Run locally

Open `index.html` in your browser.

You can also serve it with a local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
